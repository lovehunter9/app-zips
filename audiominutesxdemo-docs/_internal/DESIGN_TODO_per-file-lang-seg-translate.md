## 1. 语言：从「全局」改为「每文件」
- 现状：`config.language` 是全局的（`auto` / 语言码），转写时对每个 slice 用它或自动检测。
- 目标：
  - **自动检测仍作为全局默认**。
  - 每个文件（记录）自带一个语言字段，可覆盖全局默认。
  - 上传后的文件框、以及「初始转写 / 重新转写」时都要能选语言。
- 矛盾点（需设计）：要求「一上传就自动开始转写」与「上传时让用户选语言」冲突。
  - 候选方案：上传即用「全局默认（auto）」自动起转；用户随时可改该文件语言并「重新转写」。
  - 或：全局设置里给一个「上传后自动转写」开关；关掉后上传只入库、由用户选好语言再手动起转。
  - 需要和用户确认取舍。

## 2. 分段 / 不分段：从「全局」改为「每文件」
- 现状：`config.segmentedStt` 全局布尔。
- 目标：每文件可选整段/分段；全局值作为新文件默认。重新转写时可改。

## 3. 翻译功能（全局开关，默认关）
- 全局：翻译开关（默认关）+ 翻译模型选择。
- 生效条件：开启后必须能拿到翻译模型，否则不生效（并给出提示）。
- 能力：
  - 转录的**同时**翻译。
  - 对**已转录**的记录**后加**翻译。
  - 翻译结果尽量显示在**原文下方**，且与原文一样**支持点击 / 高亮**（词/句级同步）。
- 关闭翻译时：除「翻译开关 + 模型选择」外，所有翻译相关 UI/内容都不显示。
- 数据模型：Segment 需要能附带译文（及其 words/时间对齐，用于点击/高亮）。
