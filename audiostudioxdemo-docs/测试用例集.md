## 阶段 1 · 六大能力单独跑(每个单独勾选,其余全关)

每个用例都展开**透明执行面板**,确认 invoked/skipped 标注正确,并显示 endpoint / method / model / 耗时。

| 用例 | 素材 | 只勾 | 预期 |
|---|---|---|---|
| 1.1 STT-Whisper(英) | B | STT=faster-whisper | 转写正确,**带原生段级时间戳** |
| 1.2 STT-Whisper(中) | A | STT=faster-whisper | 中文转写出来,带时间戳 |
| 1.3 STT-Qwen | A | STT=Qwen3-ASR | 整段中文转写正确(默认**无时间戳**,整段一块) |
| 1.4 Translate(配 STT) | A | **STT + Translate**(选目标语言) | 出译文,且(分段翻译默认关)是**一整段译文,不分行、不配时间轴**。**Translate 不能单跑**(翻的是 STT 文本),必须同时勾 STT |
| 1.4b Translate 单跑(负向) | A | 只勾 Translate(不勾 STT) | 应**跳过**,面板提示「需要转写文本(请同时启用 STT)」 |
| 1.5 VAD | A | VAD | 出语音段列表(start/end) |
| 1.6 Diarize | A | Diarize | 出说话人时间线,**原生全局说话人**(S0/S1…) |
| 1.7 Embed | A | Embed | 出向量 + 相似度矩阵 |
| 1.8 Enhance | C | Enhance | 出**增强前/后对比**音频可播放 |

> **能力依赖说明**:Translate 依赖 STT(翻转写文本);Embed 的「逐说话人声纹」依赖 Diarize 才有说话人分组;融合视图依赖 STT(+VAD/DIAR)。单独跑只有 STT/VAD/Diar/Embed/Enhance 有独立输出。
>
> **翻译呈现规则(重要)**:译文是否配到时间轴**只取决于「分段翻译」开关**——
> - **关(默认)**:整段文本翻一次 → **一整段译文,不分行、不配时间轴**;**开不开 VAD/DIAR 都一样**(VAD/DIAR 只切转写,不切翻译)。
> - **开**:逐段翻译 → 每段译文配到融合时间轴(前提是有时间戳来源:VAD/DIAR、Whisper 原生、或 Qwen 开了非AI后处理)。
> - 整段模式质量:`translate.py` 已做**服务端非AI按句切分 → 批量翻译 → 拼回**(2026-06-29 修),所以整段译文**应覆盖全文、不再截断**。若仍发现明显漏译/截断,记录反馈。

## 阶段 2 · Qwen 非AI时间戳后处理开关(重点①)

> 规则:`时间戳后处理对齐` 开关**只在「选 Qwen 且不开 VAD/DIAR」时可用**。

| 用例 | 勾选 | 预期 |
|---|---|---|
| 2.1 | STT=Qwen,不开 VAD/DIAR,**关**对齐 | 转写=**整段一大块**,无时间戳 |
| 2.2 | STT=Qwen,不开 VAD/DIAR,**开**对齐 | 整段文字被**非AI算法**切成带时间戳多段,观感接近 Whisper |
| 2.3 | 切到 STT=Whisper(不开 VAD/DIAR) | 对齐开关**自动置灰**(仅 Qwen 用) |

---

## 阶段 3 · VAD/DIAR × STT 融合(重点②)

> 规则:**只要选了 VAD 或 DIAR(两个都选走 DIAR),就一定与 STT 协同出融合结果**,与对齐开关无关。

| 用例 | 勾选 | 预期 |
|---|---|---|
| 3.1 | VAD + STT(Whisper) | 融合按 **VAD 时间轴**分段(非 Whisper 原生粗段);**不碎**(已 coalesce 合并) |
| 3.2 | VAD + STT(Qwen) | Qwen 整段文字**按 VAD 段分配**出融合(始终融合,不看对齐开关) |
| 3.3 | DIAR + STT(Whisper) | 文字按说话人段落分配,带 S0/S1 |
| 3.4 | VAD + DIAR + STT | 两个都选 → 走 DIAR;出按说话人融合 |
| 3.5 | DIAR + STT + Translate(分段翻译**关**) | 转写按说话人分段上时间轴;**翻译仍是整段一块、不配时间轴**(要每段配译文须开「分段翻译」,见 4.4) |
| 3.6 | 全勾(STT+Translate+VAD+DIAR+Embed+Enhance) | 编排按依赖跑;融合视图把 STT×DIAR 对齐到统一时间轴;**翻译是否逐段上轴取决于「分段翻译」开关** |

> 3.1 是历史回归点(曾出现 VAD 没接上 STT、或碎成 21 段),重点核对。

## 阶段 4 · 分段发送开关 + 并发滑杆(重点③)

| 用例 | 勾选 | 预期 |
|---|---|---|
| 4.1 | 有 VAD/DIAR 时看「分段发送转写请求」 | 可勾;勾上后 STT **并发滑杆**激活(默认关时置灰) |
| 4.2 | 勾「分段发送转写请求」+ 调并发,跑 | 按段 fan-out 多次调 STT;面板显示**多次调用**;质量更稳 |
| 4.3 | 看「分段翻译」默认值 | **默认不勾** |
| 4.4 | 勾「分段翻译」 | 翻译并发滑杆激活;给出**依赖提醒**(需时间戳:VAD/DIAR、或 Whisper 原生、或 Qwen 开了非AI后处理) |
| 4.5 | 不满足时间戳条件时勾「分段翻译」 | 提醒文字明确点出缺时间戳 |
