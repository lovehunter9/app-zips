## 1. 概念澄清(给用户:为什么"有 Align ≠ 自动漂亮分段")

- **Align 只产出"精确时间戳"**(每个字/词的起止时间),它**不产出"分段/断句"**。
- 漂亮分段来自**文本本身的标点**(句号/逗号),或 **Diar 的说话人轮次**;Align 负责把这些段的**时间**对准。
- 所以分段逻辑(标点/Diar)和计时(Align)是**两件事**,标点驱动的断句逻辑必须存在,不能指望 Align 自动给出。
- 这也是为什么今天大量时间花在"标点/轮次怎么切 + Align 时间怎么贴"的配合上。

## 3. Demo 接入 Align(`audiostudioxdemo-app/web/src/App.tsx`)

### 3.1 交互
- 一个勾选「分段对齐」(不再叫松/紧耦合)。
- **无音频 + 文本框有文字**:可只验 Align(上传音频 + 文本框参考文本)。
- 文本框上移到上传文件下方、单独标题提示(避免误以为只用于翻译)、高度加大。
- 默认只勾 STT(最基础),其余辅助按需勾。

### 3.2 长音频(>290s)
- **客户端自动切窗**:>290s 分块、参考文本按比例切给各块,多次调 Align 再拼回(尊重模型 300s 原生上限,应用只管"逻辑一次")。
- 「窗口原语」`runAlignWindows` 统一处理 `{clip, text, offset, speaker}`。

### 3.3 融合(fused timeline)
- **Align 优先、STT 启发式兜底**:最终时间轴优先用 Align 的字/词时间。
- 三条分段路径:
  - **有骨架(Diar/VAD)+ 无标点** → `refineSegmentsWithAlign`(只用 Align 收紧边界,保留轮次)。
  - **有骨架 + 有标点** → `snapRunsToPunct`(保留 Diar 轮次时间线,把每个轮次边界**吸附到最近标点**,边界严格递增防塌缩;长轮次内部再用 `linesFromRange` 按标点/长度细分)。
  - **无骨架(纯 STT+Align)** → `groupAlignUnitsRef`(纯标点驱动:句末必断;短句不在逗号处提前断;超 `maxLen=80` 才在 cap 前最后一个逗号处断;时间按字符位置插值,空匹配段不再折叠成大块)。
- 共享辅助:`buildCharToTime`(按字符位置插值时间)、`punctLineBreaks`(纯标点+长度断行)、`linesFromRange`(区间→Seg)。

### 3.4 说话人归属
- 分段模式:整窗用**稳定说话人**(不再逐 unit 重判,避免 "a"/"the" 落进 Diar 微缝→空说话人→单词独行)。
- 整段模式:只对没有说话人的 unit 按重叠分配,再对单 unit 孤岛做中值平滑。

### 3.5 CJK 空格
- `isCJK` / `smartCat` / `joinSegText`:CJK 感知拼接,中文不再被插入多余空格(韩语本有空格,Demo 暂不优先支持)。
- 全链路文本拼接(STT 文本、alignText、fullText)统一走 `joinSegText`。

### 3.6 UI 状态透明
- 勾了 Align 时,STT 行的时间戳来源**替换**为"由 Align 强制对齐接管(精确时间)",不再误显"非 AI 后处理"。
- 有 Diar/VAD + Align 时,STT 的 `tsSource` 显示为「预分段展示(按 X 切分文本;最终时间戳由 Align 接管)」,说明这步只是展示用预分段 + 给 Align 当骨架,时间戳会被丢弃。
- STT「时间戳后处理对齐」开关:Align 启用时**逻辑禁用 + 视觉取消勾选**(不仅置灰),避免"灰着但勾还在仍触发"的疑惑。
