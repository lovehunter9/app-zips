## 关键洞察

1. **Olares 在转录赛道上"半个家底"已经搭起来了**：`whisperwebuiv2`（流派 B：自托管 Web 全栈）+ `speaches`（流派 C：OpenAI 兼容 API）+ `ollamav2`（LLM 后处理）已覆盖 70-80% 通用需求。
2. **本课题最有价值的自研方向是流派 F（AI 语音笔记本）**——Olares "个人云"定位与该流派天然契合，且现有 3 个应用都不覆盖。
3. **6 大流派中 3 个明确不该投入**：单进程桌面 App（不该上服务端）、会议机器人云（公网账号门槛 + SaaS 闭源）、闭源行业垂直（医疗/法律合规壁垒）。
4. **与"语音输入法"课题对比**：客户端复杂度大幅减少（浏览器即可），但单次任务资源占用增大；集群侧增量小但 GPU 内存峰值显著高。
5. **三阶段推荐路线工作量约 4-7 人月**，比"语音输入法"课题（旗舰 4-6 人月仅集群侧 + 客户端）显著轻。
