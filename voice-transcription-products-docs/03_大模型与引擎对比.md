# 大模型与引擎对比

> 本文聚焦"转录场景"涉及的模型与引擎选择，包括：**ASR 主干**、**说话人分离**、**翻译**、**LLM 后处理**、**视频处理辅助模型**。
> ASR 主干部分与"语音输入法"课题的模型清单**高度重合**——重合部分只给一行结论，本文重点展开"转录特有"的差异。

## 二、说话人分离（diarization）—— 转录场景特有

> 这是**与"语音输入法"课题最大的差异**：输入法不需要 diarization（用户独自说话），但转录场景几乎全靠 diarization 才有商业价值。

| # | 模型 / 库 | 协议 | 准确率（VoxConverse） | 部署 | Olares 友好 |
|---|---|---|---|---|---|
| Sp-1 | **pyannote/speaker-diarization-3.1** | MIT（gated，需 HF token 接受 license） | **事实 SOTA**，DER ~12-15% | PyTorch + HF | ★★★★★ — Olares `whisperwebuiv2` 已用 |
| Sp-2 | **WeSpeaker** | Apache-2 | 略低于 pyannote 3.1 | ONNX 可导出 | ★★★★ — 国内主流 |
| Sp-3 | **3D-Speaker**（达摩院） | Apache-2 | 与 pyannote 接近 | PyTorch | ★★★★ — 中文友好 |
| Sp-4 | **NeMo Diarization**（NVIDIA） | Apache-2 | 良好 | NeMo（重） | ★★★ — 内存重 |
| Sp-5 | **diart** | MIT | 实时版本，DER 略低 | PyTorch | ★★★ — 流式特化 |

**实操建议**：自托管路径上**直接采用 pyannote 3.1**（与 `whisperwebuiv2` 一致），需要解决"HF token 接受 gated license"——这是 Olares 应用打包时**必须文档化**的一步。

**封装层选择**：
- 学术 / 灵活：`pyannote/pyannote-audio` 直接调用
- 一站式：`MahmoudAshraf97/whisper-diarization`（Whisper + NeMo diarization 整合）
- 性能优化：WhisperX（pyannote + wav2vec2 时间戳对齐）

## 三、词级时间戳（word-level timestamps）—— 转录场景特有

> Whisper 自身给的时间戳是**句级**，误差 ±500-1000 ms；转录场景要求**词级** ±50-100 ms（字幕同步、引用、跳读）。

| 方案 | 原理 | 协议 | 误差 | 性能 |
|---|---|---|---|---|
| **WhisperX wav2vec2 forced alignment** | Whisper 转录后用 wav2vec2 强制对齐 | BSD-2/4 | ±50 ms | 70× 实时 |
| **whisper-timestamped**（linto-ai） | 改进 Whisper 自身 cross-attention 时间戳 | AGPL-3 | ±100-300 ms | 1-3× 实时 |
| **stable-ts** | 抑制 Whisper 时间戳漂移 | MIT | ±200-500 ms | 1-2× 实时 |

**实操建议**：自托管路径**优先 WhisperX**（最优精度 + 最高吞吐 + Pyannote 已集成）。

## 六、Olares 适用模型组合的"四套预设"

针对 Olares 集群的不同算力档位，给出 ASR + diarization + 翻译 + LLM 后处理的"四套搭配"：

### 6.1 入门档（CPU only / 4 GiB RAM）

| 组件 | 选型 |

## 七、与"语音输入法"课题的模型层差异

| 维度 | 语音输入法（前一课题） | 语音转录（本课题） |
|---|---|---|
| ASR 模型 | 一致（Whisper / SenseVoice / Paraformer / Parakeet 等） | 一致 |
| 模型大小偏好 | **小模型**（small/base）追低延迟 | **大模型**（large-v3）追准确率 |
| 流式 vs 批量 | 必须流式 | 通常批量；流式只在会议机器人需 |
| 说话人分离 | **不需要** | **核心需求** |
| 词级时间戳 | 不需要 | **必需** |
| AI 摘要 / 章节 | 不需要 | **核心需求** |
| 翻译 | 偶尔需要 | **常需** |
| 字幕导出 | 不需要 | **必需** |
| 量化偏好 | INT8 优先（低延迟） | FP16 优先（追准确率） |
| GPU 内存峰值 | 4-6 GiB 即可 | 8-24 GiB（含 pyannote + WhisperX） |

**简言之**：本课题在"模型层"几乎是上一课题的**升级版**——同样的主干模型，但**追求更大模型 + 更高准确率 + 更多辅助模型（diarization、对齐、翻译、LLM）**。
