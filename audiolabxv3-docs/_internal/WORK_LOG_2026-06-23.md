## 二、translate（文本→文本机翻，NLLB）✅ 引擎级

### 2.1 重新定义 translate mode

关键纠偏（用户提出）：**STT 模型原生就支持「语音→英文」翻译**（Whisper 的 `/v1/audio/translations`），那条能力随 stt 暴露、不该再占 `translate` mode。`translate` 专指**文本→文本机翻**（以及未来语音→任意语种）。对照 boss 图，boss 心中的 translate ≈ NLLB 这类多语机翻。

### 2.2 实现：复用 whisper 镜像，零新镜像

- 范例模型 `entai2965/nllb-200-distilled-600M-ctranslate2`（CT2 格式）。
- 复用 `beclab/fedirz-faster-whisper-server` 镜像——它**本就自带 `ctranslate2` + HF `tokenizers`**；NLLB 的 CT2 repo 自带 `tokenizer.json`，`tokenizers` 直接读，**无需 sentencepiece**。
- 新增 `/wrappers/translate.py`：FastAPI，`POST /v1/translate {text, target, source?}`（FLORES-200 语种码），CPU 跑。NLLB 编码 = `[src_lang] + subwords + </s>`，解码 `target_prefix=[tgt_lang]`。
- `engine.yaml` 加 `translate` 条目（复用 whisper 镜像 + `cmd` 跑 wrapper）。`OlaresManifest.yaml` 加 mode 选项与示例。

### 2.3 商用风险核实

NLLB 模型本体 **CC-BY-NC 4.0（非商用）**——但我们只是**提供下载与运行支持**，模型由用户自行选择，平台侧不承担其许可限制（同理用户也可选商用许可的机翻模型）。结论：**支持，风险归用户选择**。

### 2.4 验证

引擎级端到端通过：EN→ZH、EN→JA 等方向翻译正确。

> 待办：`translate` 接入 LLM Gateway（需 `/v1/translate` 的 **JSON-in** 透传路由 + `ModeTranslate`），归入 test5 镜像那批 Gateway 侧改动。

## 四、embed（说话人/音频向量）✅ 引擎级

### 4.1 实现：复用 pyannote 镜像，零新镜像

- 范例模型 `pyannote/embedding`（512 维 x-vector）。
- 复用 `beclab/maximsachs-pyannote_fastapi:4.0.4`——`pyannote.audio` 的 `Model + Inference(window="whole")` 把整段音频转成一个定长向量。
- 新增 `/wrappers/embed.py`：`POST /v1/audio/embeddings`（multipart → 单向量）。自解码音频（soundfile/torchaudio/wave 三级兜底）**绕过该镜像里坏掉的 torchcodec `AudioDecoder`**（与 diar 同款问题）。CPU 可跑（GPU=0）。

### 4.2 踩坑与修复

1. **门禁 401/403**（`GatedRepoError`）：`pyannote/embedding` 是 gated repo。解决 = 用户去 `huggingface.co/pyannote/embedding` 同意条款（与 diar 同款流程），HF_TOKEN 自动注入。
2. **`ModuleNotFoundError: omegaconf`**：该 checkpoint pickle 了 omegaconf 配置对象，`torch.load` 需要它；但此 pyannote 镜像带 pyannote.audio 却**不带 omegaconf**（diar 的 Pipeline 路径不踩它）。修复 = `embed.py` 首次加载时**按需 `pip install omegaconf`**（无新镜像，节点层缓存）。

### 4.3 验证

引擎级端到端通过：返回 512 维向量。

> 待办：`embed` 接入 LLM Gateway（`/v1/audio/embeddings` 透传），归入 test5 批次。

## 五、enhance（降噪/语音增强）✅ 引擎级（今天收尾的最后一项）

### 5.1 选型

方向曾考虑 DeepFilterNet（非 HF 原生分发，从 GitHub release 拉，**不契合 llm-init 下载范式**），改用 **SpeechBrain 系**（HF 原生、与 pyannote 镜像的 torch 栈兼容）。范例定 **`speechbrain/mtl-mimic-voicebank`**（**apache-2.0，商用安全**，16k 单声道，CPU 友好）；`sepformer-wham16k-enhancement`（也是 apache-2.0）列为下一个候选。

### 5.2 实现：复用 pyannote 镜像，零新镜像

- 新增 `/wrappers/enhance.py`：`POST /v1/audio/enhance`（multipart 音频入 → `audio/wav` 增强音频出，带 `X-Audio-Model`/`X-Audio-Mode` 头）。
- pyannote 镜像带 torch，但**不带 speechbrain** → 首次加载**按需 `pip install speechbrain`**（同 embed 的 omegaconf 套路）。
- 自解码到 16k 单声道（自做重采样），绕过坏掉的 torchcodec。
- `engine.yaml` 加 `enhance` 条目（复用 pyannote 镜像 + `cmd`）；`OlaresManifest.yaml` 加 mode 选项与示例。

### 5.3 踩坑与修复（两个真问题）

1. **`Need hparams['compute_stft']`**：起初用 `SpectralMaskEnhancement` 加载 `mtl-mimic-voicebank` 失败——该模型实为 **`WaveformEnhancement`**（不同增强 repo 的 hyperparams.yaml 决定用哪个类）。修复 = **自动探测**：依次试 `WaveformEnhancement` / `SpectralMaskEnhancement` / `SepformerSeparation`，谁 `from_hparams` 成功用谁；推理时按类分派（sepformer 用 `separate_batch` 取 source 0，其余用 `enhance_batch`）。这样基座对多种 SpeechBrain 增强模型通用。
2. **device 字符串**：SpeechBrain 不接受裸 `"cuda"`（`not enough values to unpack`），改为 **`"cuda:0"`**。

### 5.4 验证（公网单入口，public 无 SSO）

实例 `audiolabxv31c4d10`，入口 `https://2c7f7a17.olarestest003.olares.com/`：
- 引擎日志：speechbrain 安装成功 → `loaded as 'waveform' on cuda:0` → `/healthz` 持续 200，pod `1/1`。
- `GET /v1/models` → `mtl-mimic-voicebank`（mode=enhance）。
- `POST /v1/audio/enhance`（jfk.flac）→ **HTTP 200**，`content-type: audio/wav`，头部 `x-audio-model: mtl-mimic-voicebank` / `x-audio-mode: enhance`。
- 落地 wav 校验：**16000Hz / 单声道 / 16-bit PCM / 10.99s**（与输入同时长），非静音（peak 0.784，rms 4600）。

> 待办：`enhance` 接入 LLM Gateway（`/v1/audio/enhance` 透传，**JSON/二进制音频出**），归入 test5 批次。

## 八、关键纪律 / 经验沉淀

- **零新镜像三连**：translate（whisper 自带 ctranslate2+tokenizers）、embed（pyannote + 按需 omegaconf）、enhance（pyannote + 按需 speechbrain）。「核心在模型」——镜像只是驱动，能复用就复用。
- **按需 pip 装依赖**是规避「为一个小依赖打新镜像」的有效手段（omegaconf、speechbrain 均如此），代价是每个新 pod 首启多花 ~1 分钟装包（节点层会缓存）。
- **torchcodec 坑**：pyannote 镜像的 `AudioDecoder` 坏（`name 'AudioDecoder' is not defined`），所有 pyannote 系 wrapper（diar/embed/enhance）统一**自解码喂 in-memory 波形**绕过。
- **SpeechBrain 增强模型不止一个类**：waveform / spectralmask / sepformer，必须按 hyperparams 自动探测，别写死。
- **市场重传偶发 hydration 失败**：`market upload` 第一次报 `control characters are not allowed`（实为服务端 hydration 偶发），重试即过——已确认源文件无控制字符（PyYAML 解析通过、逐字节扫描干净）。脚本里加了重试。
- **gated repo**（pyannote/embedding 等）：HF token + 浏览器同意条款，缺一不可。
- **public 入口验证**：`olares-cli settings apps entrances list` 当前**不回填 URL**（显示 `-`），实例公网 URL 仍需从桌面/LarePass 拿；入口 public 时可直接 curl，无 SSO。
- 版本仍**锁 1.0.0**，同版本重传先 `market delete audiolabxv3 --version 1.0.0` 再 `upload`；`templateOnly` 的 clone 必须用 `-s upload` 指定源 + `--title` + 全套 `--env`。
