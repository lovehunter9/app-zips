olares-cli + olares-skills 上手指南(安装 · 连接 · 使用)

一句话:olares-cli 是命令行"遥控器"(一个二进制),olares-skills 是给 AI 助手(Cursor/Claude 等)看的"说明书"。两者都装在你本地电脑;真正装应用、跑容器、模型推理/GPU 都在远端那台 Olares 机器上,本地只是驾驶座。

【0. 前置】
- 一台已装好 Olares OS 的机器 + 你的 Olares ID(形如 name@xxx.olares.com)。
- 本地有 node / npx。
- 只有"源码编译"路线才需要 git + Go(版本无所谓,GOTOOLCHAIN=auto 会自动拉)。

【1. 安装 olares-cli(二选一)】

路线 A:npm 一键(推荐)
    npx @olares/cli@latest install
  它会装好 olares-cli 并装上官方 skills。注意:不装 Olares OS、不自动登录。

路线 B:本地源码编译(想要最新 / 内部要求)
    git clone https://github.com/beclab/Olares.git ~/beclab/Olares
    cd ~/beclab/Olares/cli
    go build -o olares-cli ./cmd/main.go
    ln -sf "$(pwd)/olares-cli" /opt/homebrew/bin/olares-cli   # 放进 PATH(macOS)
    olares-cli --version    # 源码编译显示 0.0.0-development 是正常的
  注意:必须克隆整个仓库(cli 依赖 ../framework/oac,只克隆 cli 子目录编不过)。

【2. 登录(把遥控器连到那台 Olares)】
这步必须本人做(要输密码/2FA):
    olares-cli profile login --olares-id <你的Olares-ID>
    olares-cli profile whoami      # 看身份/角色
    olares-cli profile list        # 看所有 profile、当前用哪个、后端版本
  注意:没有 profile current 这个命令;查状态用 whoami / list。token 存在系统钥匙串。

【3. 安装 skills(让 AI 照着说明书干活)】
路线 A 已自带。源码版 / 想用本地仓库版:
    cd ~/beclab/Olares/cli
    npx skills add "$(pwd)/skills" --skill '*' -a cursor -g -y
  说明:装到 ~/.agents/skills/olares-*;切忌加 sudo;卸载用 npx skills remove beclab/Olares -y -g。
  在 Cursor 里要新开一个对话,skills 才会自动进 AI 的技能清单。
  怎么确认 AI 真在用 skill:看它动手前有没有读 ~/.agents/skills/olares-*/SKILL.md。

【4. 怎么用】
命令结构:olares-cli <area> [<noun>] <verb> [flags]
- --help 是 flag 的权威来源,如 olares-cli market --help
- 只读命令大多支持 -o json;写操作默认要确认,脚本里加 --yes

常用命令:
    # 市场 / 应用生命周期
    olares-cli market list --mine                 # 我装了哪些 app
    olares-cli market status <app> --watch        # 盯状态到终态
    olares-cli market install <app> --watch
    olares-cli market clone <base> -s upload --env K=V --watch
    # 集群运行时
    olares-cli cluster pod list
    olares-cli cluster pod logs <pod> -f
    olares-cli cluster application list
    # chart 开发(本地,无需登录)
    olares-cli chart from-compose --name <app> -f docker-compose.yml
    olares-cli chart lint ./<app>
    olares-cli chart package ./<app> -o ./dist
    olares-cli market upload ./dist/<app>-<ver>.tgz
    # 设置 / 文件 / 仪表盘
    olares-cli settings apps list
    olares-cli files ls /drive/Home
    olares-cli dashboard overview gpu -o json

让 AI 帮你做事的典型话术:
- "把这个 repo / docker-compose 移植成 Olares app 并装上"
- "在我的 Olares 上跑某个 HuggingFace 模型"
- "看看 xxx 这个 pod 为什么挂了"

【5. 排错速查】
- command not found: olares-cli → 没进 PATH;源码编译记得做软链
- 任意命令 401/403/459 → token 过期,重新 profile login
- app 'X' is not installed → 先 install 或核对名字
- 上传的 chart 装不上/看不到 → install/clone 记得带 -s upload
- AI 没"用 skill" → 新开对话让 skills 自动加载

【6. 卸载】
    npm uninstall -g @olares/cli           # 路线 A 的客户端
    rm -f /opt/homebrew/bin/olares-cli     # 路线 B 的软链
    npx skills remove beclab/Olares -y -g  # 移除 skills
    olares-cli profile remove <名字>        # 清除某身份的本地 token
