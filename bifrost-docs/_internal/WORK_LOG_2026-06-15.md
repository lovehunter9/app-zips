- 机制参考 opencode 的 `--shell=opencode`：`--shell` 可直接指任意可执行名。
- `bifrost-cli-docker/Dockerfile`：新增入口脚本 `/usr/local/bin/bifrost-shell`：
  ```bash

  bifrost        # 进入即启动 CLI
  exec bash      # 退出 CLI 后落交互式 bash（uid 1000 / HOME=appData）
  ```

- `bifrost/templates/terminal.yaml`：`--shell=bash` → `--shell=bifrost-shell`。
