# 源音频上传位置

把以下 **两个文件** 上传到本目录（保持原文件名即可）：

| 期望文件 | 检测依据 |
|---|---|
| `流浪地球02：飞船派和地球派  于和伟演播.mp3` | 文件名含 CJK 字符 → 识别为中文源 |
| `adventureholmes_02_doyle_64kb.mp3` | 文件名纯 ASCII → 识别为英文源 |

脚本支持的格式：`mp3 / wav / m4a / flac / webm / mp4`。

## 检测原则

`prepare_audio.sh` 通过 **文件名是否含 U+4E00-U+9FFF 区间字符**（CJK Unified Ideographs）来分组。任何文件名含中文字的文件 → 中文源；其他 → 英文源。

每组应只有一个文件，多于一个时脚本会取**最大的那一个**（避免误用碎片）。

## 占位检查

`audio/source/` 应至少有 2 个音频文件（含 1 中 1 英），否则 `prepare_audio.sh` 会以非零退出码失败并提示。
